Whirlpool Washer F5 E2 Error Code: What It Means and How to Fix It

Some fixes need a technicianAbout 10 minutesAlso shown as F05 E02
Short answer: F5 E2 means the washer cannot lock the door (front loaders) or lid (top loaders). Whirlpool's first suspects are a door that looks closed but is not latched, and laundry or an object blocking the lock area.

Fix it yourself: four checks, in order

  1. Close the door or lid firmly. It can look shut without being latched. Open it and close it firmly.
  2. Clear the lock area. Check that no clothing sticks out past the door opening, and remove anything in the lid lock area on top loaders.
  3. Reduce the load. Leave enough room for the laundry to tumble freely so it does not press against the door.
  4. Clear the code and reset. On many front loaders, press Pause or Cancel twice and Power once to clear the code. If it returns, unplug the washer for 5 minutes and plug it back in.

Start the cycle again and listen for the lock engaging.

When to call a technician

If the code comes back with the door clearly latched and nothing in the way, Whirlpool recommends scheduling service. The usual fault is the door lock or door switch.
