Samsung Washer dC Error Code: What It Means and How to Fix It

Some fixes need a technicianAbout 5 minutesAlso shown as dE, DC1, dE1
Short answer: dC (or dE) means the washer detects that the door is open or not securely closed while it tries to run. Usually the door simply is not latched, or a piece of laundry is caught in the seal. If the door is properly closed and the code stays, the door switch may be faulty.

Fix it yourself: four checks, in order

  1. Close the door firmly. Open it, then push it shut until you hear the latch click.
  2. Check the door seal. Look around the rubber seal for a sleeve, sock, or towel corner caught between the door and the washer.
  3. Reduce the load. An overfilled drum can push against the door and stop it from closing properly. Remove some items.
  4. Check child lock. On some models a door code can appear when Child Lock is on and there is water in the drum. Turn Child Lock off as described in your manual.

Unplug the washer for one minute, plug it back in, and start a cycle.

When to call a technician

If the door is clearly latched and nothing is caught but the code returns, Samsung points to a faulty door switch or door lock, or less often the main control board. These need a technician.
