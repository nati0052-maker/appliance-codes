GE Dishwasher C1 Error Code: What It Means and How to Fix It

Usually an easy fixAbout 15 minutesMeans slow drain
Short answer: C1 means the drain pump ran for more than 2 minutes to empty the tub. The dishwasher is still draining, just too slowly. The usual cause is a partial blockage somewhere between the dishwasher and the sink drain: the air gap, the drain hose, or the garbage disposer inlet.

Fix it yourself: five checks, in order

  1. Run the garbage disposer. If the dishwasher drains into a disposer, run it with cold water for a few seconds. Food left in the disposer can back up the dishwasher drain.
  2. Clean the air gap. If there is a small chrome or plastic cap on the sink deck next to the faucet, that is the air gap. Lift off the cover, unscrew or pull off the inner cap, and clear out any food or buildup. Rinse it and put it back.
  3. Check the drain hose. Follow the hose under the sink. Straighten any kinks, and reposition it if it is crushed behind items in the cabinet or sags low enough to hold water. A hose that is damaged or badly kinked should be replaced.
  4. Check for a new disposer plug. If a disposer was just installed, the knockout plug inside its dishwasher inlet may never have been removed. That blocks the drain completely, so it often shows up as a drain code right after the install.
  5. Run a short cycle. Start a rinse or short cycle and listen for the drain. If the code does not return, the problem is solved.

If your model has a removable filter at the bottom of the tub, cleaning it is also worth doing while you are there. A clogged filter slows water on its way to the pump.

When to call a technician

If you have cleaned the air gap, cleared the hose and run the disposer and C1 keeps coming back, GE recommends contacting service. A drain pump that is weak or partly blocked inside needs the dishwasher opened up, which is a job for a technician. If the dishwasher stops draining at all, see the C3 code below.
